# External technical references checked for this kit

Checked: 21 September 2026. These sources support installation and tool descriptions, not the substantive law briefs. The custom skill and catalog were authored for this request; they are not official Anthropic or Remotion products.

1. Claude Code — Skills: https://code.claude.com/docs/en/skills
   Project-scoped `.claude/skills/<name>/SKILL.md`, YAML frontmatter, slash invocation and progressive loading.
2. Claude Code — MCP: https://code.claude.com/docs/en/mcp
   Local stdio MCP server registration and scopes.
3. Microsoft — Playwright MCP: https://github.com/microsoft/playwright-mcp
   Official Claude Code integration and browser inspection capabilities.
4. Anthropic — frontend-design skill: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md
   Optional interface/art direction guidance; it does not supply an animation library.
5. Vercel Labs — skills CLI: https://github.com/vercel-labs/skills
   Repository install, skill selection and `--agent claude-code` options.
6. Remotion — Agent Skills: https://www.remotion.dev/docs/ai/skills
   Optional Remotion-specific guidance, not required for this standalone JS library.

External commands can change. Review the repository/source selected by the installer and record installed versions. Do not install a random similarly named package or grant permissions blindly. The kit contains no redistributed third-party skill bodies, fonts or artwork.
