# Reading map

This is a project-scoped skill. All paths below are relative to the kit/project root, not this references directory.

- `docs/RUNTIME_CONTRACT.md`: JS interface, pure time evaluation and packing.
- `docs/VISUAL_STANDARD.md`: artwork, characters, layouts and motion.
- `docs/LEGAL_CONTENT_POLICY.md`: illustrative examples vs verified law.
- `docs/PRODUCTION_WORKFLOW.md`: pilot, batches and checkpoints.
- `docs/ACCEPTANCE.md`: actual gates and evidence.
- `briefs/index.json`: 50 categories / 500 motifs / 2,000 IDs.
- `briefs/catalog.jsonl`: canonical individual briefs; select with CLI.
- `briefs/pilot.json`: first quality gate.

Copy the whole kit when moving the skill to a different project. Copying this SKILL.md alone does not install its catalog or supporting instructions.
